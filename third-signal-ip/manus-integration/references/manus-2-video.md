# Manus 2.0 video production

Verified 2026-10-14. Manus 2.0 describes Cascade, Studio, Video Editor, Game Dev, Cloud Computer, Remote Control, Automations and Cue. Alchemy combines creative direction with video/code generation. These are product descriptions, not guarantees of tool access.

Sources: https://www.manus.im/blog/introducing-manus-2-0 and https://www.manus.im/features/video

1. Resolve current canon and inspect actual references. A later character sheet overrides an older scene's identity; retain the old scene only for its explicitly surviving function.
2. Give each reference one job. Character sheets control identity; a scene still controls staging; footage controls motion/style only to the declared extent. Do not animate an entire multipanel comic or lineup as one camera frame.
3. Build a timed shot map with objective, spatial relationship, action, change and audio. Prefer one coherent action per shot and specific camera movement. For a fictional power show trigger → operation → physical consequence → response; decorative glow does not prove the mechanic.
4. Confirm cost and output scope. Free offers must be observed on the active account and submission surface; UI eligibility does not establish API eligibility. Do not assume every model, resolution, edit or reroll is included.
5. Generate only the missing approved shots. Reuse sound existing footage and repair failed shots selectively. Preserve originals and version candidates.
6. Edit with a real timeline or explicit EDL. Importing an MP4 from Flow/OpenArt transfers pixels, not its editable scenes or character registry. Check aspect and padding instead of silently cropping off hands/weapons.
7. Save and reopen the project, verify shot order and total duration, review full playback/audio, and retrieve the final MP4 plus source clips/project reference. Public release remains separate.
