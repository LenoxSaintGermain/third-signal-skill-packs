# WIND command examples

Use these as shorthand prompts. Replace the bracketed text with the current IP's subject or context.

## Single spread

`WIND this: [idea].`

Return one situational spread with a title, narrative job, hero moment, extracted design canon, evidence panels, emotional beat, forward hook, and continuity impact.

## New subject

`WIND the faction: [faction].`

Show the faction performing a consequential action. Derive doctrine, hierarchy, resources, visual language, internal contradiction, and opposition from the event.

## New visual direction

`WIND it. New skin. The IP should feel like [references, materials, mood, and audience].`

Keep the narrative-spread grammar. Define a fresh skin before proposing a render.

## Connected development

`WIND sequence: develop [subject/world] across [number] spreads. Alternate IMMERSION and SPINE.`

Return an ordered arc in which every spread has a different narrative job and changes what the audience understands.

## Rendering

`WIND Render: use the approved [spread title] plan in the current skin.`

Create the actual visual artifact. Preserve the hero composition, scale, canon, evidence hierarchy, and continuity.
