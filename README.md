# Third Signal Skill Packs

**Research documentation hub for AI-native development capabilities**

This repository houses specifications, research documentation, and implementation guides for Third Signal's portfolio of agentic development tools. Each skill pack addresses a specific capability gap in AI-native software development.

---

## The ARSENAL

### 🟢 PRODUCTION (Ship-Ready)

**[Continuous Context Protocol (CCP)](./continuous-context-protocol/)** - `$40–120M valuation`
> Hierarchical memory compression for agentic systems. Solves AI amnesia by forcing agents to document their work, then compresses context as projects scale.
>
> **Status**: PRODUCTION | **Category**: AI Infrastructure

**[Librarian + Chronicle](./librarian-chronicle/)** - `$20–50M valuation`
> Autonomous documentation & intent-preserved decision log. Every WHY and HOW preserved at ingest time, not reconstructed retroactively.
>
> **Status**: PRODUCTION | **Category**: Developer Intelligence

---

### 🟡 POC (Proof of Concept)

**[Ghost Intelligence](./ghost-intelligence/)** - `$10–25M valuation`
> Contextual ambient reasoning engine. Proactive AI that surfaces what's relevant before you know to ask.
>
> **Status**: POC | **Category**: Reasoning Interface

---

### 🔴 SPEC (Research Preview)

**[COE Cookie](./coe-cookie/)** - `$25–75M valuation`
> Tamper-proof AI ROI telemetry. Cryptographic signing + AI-powered task classification. The receipt that justifies the expense.
>
> **Status**: SPEC | **Category**: AI Governance

**[MNEME](./mneme/)** - `$30–100M+ valuation`
> Multimodal neuro-emotional memory engine. Cross-model, cross-session, user-owned memory protocol. The OAuth of AI memory.
>
> **Status**: SPEC | **Category**: Memory & Continuity

---

## 🛡️ Standards & Frameworks

**[A.E.G.I.S. Standard v1.0](./aegis-standard/)** - Research Preview

>
> **Status**: Research Preview | **Category**: AI Security

## Using This Repository

### For Developers

Each skill pack directory contains:
- **README.md**: Full specification + implementation guide
- **examples/**: Reference implementations
- **tests/**: Validation test suites
- **status.json**: Current development status + roadmap

### For Researchers

Research previews (SPEC status) include:
- Problem statement + threat model
- Detection heuristics + validation corpus
- Integration patterns
- Open questions + research roadmap

### For Product Teams

Production-ready packs include:
- Deployment guides (Cloud Run, Docker, npm)
- API documentation
- Pricing models + ROI calculators
- Case studies
